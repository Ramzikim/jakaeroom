# 작애의 방 — playable v001

프로젝트 루트의 `Start_Jakae.cmd`를 실행하고 http://127.0.0.1:3000 을 엽니다. Node.js와 설치된 `node_modules`를 사용합니다. 같은 주소의 서버가 이미 실행 중이면 브라우저만 열면 됩니다.

## 개발과 검증

`web` 폴더에서 실행합니다. 시스템 npm 실행 경로가 잘못되어 있어도 아래 명령은 사용할 수 있습니다.

```powershell
node node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3000
node node_modules/next/dist/bin/next build
node --experimental-strip-types tests/life.test.ts
```

개발 결과는 `.next-dev`, 배포용 빌드 결과는 `.next`에 저장됩니다. 외부 배포와 런타임 AI API는 사용하지 않습니다.

## 자산과 동작

- 기존 상세 환경 `public/models/room.glb`에서 `scripts/prepare-room.mjs`로 웹용 `room-web.glb`를 생성했습니다. 원본 Blender 파일과 기존 GLB는 변경하지 않았습니다. 48개 정적 메시, 약 11.3만 삼각형, 최대 1024px 텍스처, WebP 및 Meshopt 압축을 사용합니다.
- 작애는 `app/jakae.ts`에서 승인 모델시트를 기준으로 새로 구성한 관절형 웹 메시입니다. 기존 거절된 캐릭터 GLB는 로드하지 않습니다. 기본 초록 꽃옷을 입고 있으며 머리, 팔, 다리, 눈을 독립적으로 움직입니다.
- `app/life.ts`의 가구를 피하는 연결 경로와 지역별 대사를 사용합니다. 쓰담쓰담·딸기는 산책을 잠시 멈추며, 침대 요청은 현재 경로를 마친 뒤 안전한 통로로 이어집니다.
- 편지는 로컬 메시지 12개 중 무작위로 선택합니다. 수치형 상태·육성 지표는 없습니다.
- 시간은 기기 시간대와 무관하게 UTC+9로 계산합니다. 조명 구경 메뉴에서 다섯 시간대를 확인한 뒤 실시간으로 복귀할 수 있습니다.
- 카메라 회전·확대, 전체 구도 복귀, 작애 따라가기, 반응형 터치 UI를 지원합니다.

## v001 한계

캐릭터는 봉제인형의 모양을 재현한 절차적 메시와 관절 애니메이션이며, 최종 조각·스킨 변형·털 렌더링은 아닙니다. 침대로 오르내리기는 보간된 동작입니다. 옷 갈아입기, 미미, 목욕, 고급 게임 동작은 후속 범위입니다. 실제 모바일 기기 GPU 검증은 별도로 필요합니다.
